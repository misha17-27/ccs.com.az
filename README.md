# ccs.com.az — Cost Control Services

Сайт компании Cost Control Services (контроль затрат для ресторанов и HoReCa, Баку).

## Сайт (PHP, дизайн V1)

Из трёх прототипов утверждён V1 (тёмный премиум); V2 и V3 удалены, из V3 перенесён калькулятор фудкоста.
Сайт — PHP без фреймворков: весь контент берётся из базы админ-панели.

| Адрес | Страница | Блоки |
|-------|----------|-------|
| `/` | Главная | первый экран и цифры, о нас, услуги, калькулятор, клиенты, опыт, видео TikTok, заявка, Instagram |
| `/haqqimizda` | О нас | о нас, опыт, клиенты, заявка |
| `/xidmetler` | Услуги | услуги, калькулятор, заявка |
| `/musteriler` | Клиенты | клиенты, опыт, заявка |
| `/suallar` | Вопросы | вопросы и ответы, заявка |
| `/elaqe` | Контакты | заявка, видео TikTok, Instagram |

Русская и английская версии — `/ru/…` и `/en/…` со своими адресами (например, `/ru/uslugi`, `/en/services`). Адреса меняются в админке → Səhifələr отдельно для каждого языка; прежние адреса вида `/ru/xidmetler` перенаправляются (301) на новые. `/sitemap.xml` (простой список всех адресов) и `hreflang` строятся автоматически, `/v1/`, `/v2/`, `/v3/` ведут на главную.

**Как устроено.** `index.php` — роутер: язык из адреса, страница по адресу из базы, 404 для остального. Шаблоны — `app/views/` (`page.php` — шапка, меню, подвал; `sections/` — блоки). Логика — `app/site.php`, надписи интерфейса (кнопки, подписи формы, калькулятор) — `app/site_lang/{az,ru,en}.php`; всё остальное редактируется в админке. Стили — `assets/css/site.css`, скрипты — `assets/js/site.js`.
Если перевод текста пустой, на сайте показывается азербайджанский вариант. В текстах можно выделять: `*слово*` — цветной акцент, `**слово**` — жирный.

Общие файлы — `assets/img/`: логотип (SVG, восстановлен по презентации), логотипы 18 клиентов, 3D-рендеры и фото из презентации.

### Локальный просмотр

`php -S 127.0.0.1:8082 -t . index.php` → http://localhost:8082/ (последний аргумент — роутер; админка — http://localhost:8082/admin/).
Для локальной базы создайте `app/config.local.php` с `define('PRIVATE_DIR', dirname(__DIR__) . '/.private');` — оба пути в `.gitignore`.

### Деплой (cPanel → Git Version Control)

Репозиторий клонируется в `/home/ccscom/repositories/ccs.com.az`. При «Deploy HEAD Commit» cPanel выполняет `.cpanel.yml`: копирует `index.php`, `robots.txt`, `assets/`, `api/`, `admin/`, `app/`, `uploads/` в `/home/ccscom/public_html/`, удаляет старые прототипы (`v1/`–`v3/`, `index.html`) и вписывает правила адресов из `deploy/htaccess.conf` в `public_html/.htaccess` между строками `# BEGIN CCS` / `# END CCS` (остальное содержимое файла, например версия PHP от cPanel, не трогается).
Порядок: Manage → Pull or Deploy → Update from Remote → Deploy HEAD Commit.

Сайт идёт через Cloudflare, который кэширует CSS/JS на несколько часов. Ссылки на них получают `?v=<время изменения файла>`, а деплой копирует файлы заново — после каждого деплоя браузеры и Cloudflare сразу берут новые версии.

**Обновление базы.** При первом открытии сайта или панели после деплоя база сама переходит на новую схему. Тексты, услуги, вопросы и SEO, которые никто не менял в админке, заменяются текстами V1 и получают переводы RU/EN; всё, что вы уже отредактировали, остаётся как есть (пустые переводы дополняются только у нетронутых полей).

## SEO

Главный ключевой запрос — **restoran auditi / аудит ресторана / restaurant audit** (Баку): он стоит в начале title, в H1 и в текстах страниц. Всё это меняется в админке (Səhifələr и Mətnlər). Каждая страница отдаёт `canonical`, `hreflang` для AZ/RU/EN, Open Graph и данные schema.org (JSON-LD): компания (`ProfessionalService`) с адресом, телефоном и услугами, хлебные крошки на внутренних страницах и `FAQPage` на странице вопросов. Картинка для соцсетей по умолчанию — `assets/img/og-image.jpg` (1200×630); своя картинка страницы или главной в Səhifələr её заменяет.

## Блог

Список статей — `/bloq`, `/ru/blog`, `/en/blog`; статья — `/bloq/<адрес>` (адреса RU/EN свои). Пока в **Bloq** выключено «Bloq saytda görünsün», блога нет в меню, подвале и `sitemap.xml`, а его страницы отдают `noindex`; по прямой ссылке их можно открыть и проверить. Статьи дают schema.org `BlogPosting` и хлебные крошки «Главная → Блог → Статья». Картинки статей лежат в `uploads/blog/` — включайте папку в резервные копии.

## TikTok

На главной (после блока «Опыт») и на странице контактов — блок TikTok (`app/views/sections/tiktok.php`): заголовок и текст из **Mətnlər → TikTok**, превью пяти роликов (`assets/img/tiktok/`) и кнопка «TikTok-da izləyin». Всё ведёт на профиль из **Parametrlər → TikTok linki**. Список видео не ведётся: TikTok не отдаёт сайтам ролики профиля без одобренного приложения разработчика.

## Instagram — лента последних публикаций

На главной и на странице контактов — сетка из 12 последних постов @costcontrol.services (`assets/js/instagram-feed.js`, стили — `assets/css/instagram-feed.css`).

Откуда берутся посты:

1. `api/instagram.php` — живые данные через официальный Instagram API (Instagram Login). Ответ кэшируется на 30 минут, обложки сохраняются в `public_html/media/instagram/`, токен продлевается автоматически раз в неделю (живёт 60 дней).
2. Пока токена нет или API недоступен — `assets/data/instagram.json`: снимок 12 публикаций на 28.10.2026 (обложки в `assets/img/instagram/`).

Нужны PHP 8.0+ с расширением curl.

### Подключение токена (один раз)

1. Аккаунт Instagram должен быть профессиональным (Бизнес или Автор): Настройки → Тип аккаунта и инструменты.
2. [developers.facebook.com](https://developers.facebook.com/apps/) → Create App → добавить продукт **Instagram** → **API setup with Instagram login**.
3. В блоке «Generate access tokens» добавить аккаунт `costcontrol.services` (вход в Instagram) и нажать **Generate token**. Нужно разрешение `instagram_business_basic`.
4. Вставить токен в админ-панели: **Instagram → Подключить Instagram** (сохраняется в `/home/ccscom/ccs-private/instagram-token.txt`).
5. Открыть https://ccs.com.az/api/instagram.php — в ответе должно быть `"source":"live"`.

Токен никогда не попадает в браузер и в репозиторий. Если его отозвать или он истечёт, сайт продолжит показывать последние сохранённые публикации; новый токен — заменить там же, в панели.

**Где что лежит.** Код: `admin/` (страницы), `app/` (ядро — закрыто от веба через `.htaccess`), `api/contact.php` (приём формы). Данные: SQLite-база `/home/ccscom/ccs-private/ccs.sqlite` — вне `public_html`, создаётся и заполняется текущим контентом сайта автоматически при первом открытии панели. Загруженные картинки — `public_html/uploads/` (запуск скриптов там запрещён).
**Бэкап** — скачать папку `ccs-private` и `public_html/uploads`.

### Первый вход

1. После деплоя открыть https://ccs.com.az/admin/ — откроется «İlk administrator».
2. В cPanel → File Manager открыть `/home/ccscom/ccs-private/setup-code.txt` и ввести код из файла (так первого админа не создаст посторонний).
3. Заполнить имя, e-mail и пароль (от 10 символов). После этого страница настройки отключается навсегда, код удаляется.

### Безопасность

Пароли — bcrypt; после 5 неверных попыток для e-mail (или 10 с одного IP) вход блокируется на 15 минут; сессия — HttpOnly/SameSite cookie, выход через 4 часа бездействия; CSRF-токен на всех формах; CSP и запрет встраивания во фреймы; загружаются только JPG/PNG/WebP со случайными именами. Cloudflare Turnstile на форме входа включается вставкой ключей в Parametrlər.
Форма на сайте: скрытое поле-ловушка для ботов, проверка Origin, не больше 5 заявок с одного IP за 10 минут.
